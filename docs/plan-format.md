# Study plan file (`examprep-plan` v1)

A plan is one JSON file. Import it in **ตั้งค่า → แผนการเรียน** or on first launch.
The bundled teacher plan is `public/plans/teacher-m1-2570.json`, generated by
`node scripts/build-teacher-plan.mjs` from the paper calendar "ปฏิทินเตรียมสอบเข้า ม.1".

```jsonc
{
  "format": "examprep-plan", "version": 1,
  "title": "ปฏิทินเตรียมสอบเข้า ม.1",
  "profile": { "school": "", "studentName": "", "teacherName": "", "targetScore": null },
  "exam": {
    "name": "สอบเข้า ม.1", "date": "2027-03-27", "totalScore": 200,
    "sessions": [{ "subject": "thai", "start": "09:00", "minutes": 40, "questions": 40 }]
  },
  "subjects": [{ "id": "math", "name": "คณิตศาสตร์", "color": "#4f46e5" }],
  "phases": [{ "id": "chapters", "name": "โจทย์ท้ายบท", "start": "2026-11-09", "end": "2027-01-21", "goal": "…" }],
  "restWeekdays": [0],
  "sets": [{ "id": "prep-math-01", "subject": "math", "kind": "chapter", "name": "บทที่ 1 …", "count": 15 }],
  "tasks": [{
    "id": "2026-11-09-practice-prep-math-01-1", "date": "2026-11-09", "type": "practice",
    "subject": "math", "set": "prep-math-01", "from": 1, "to": 15, "minutes": null, "title": "บทที่ 1 … · 15 ข้อ"
  }],
  "mocks": [{ "n": 1, "date": "2027-02-06", "note": "ข้อสอบเก่า / แหล่งอื่น" }]
}
```

| Field | Notes |
|---|---|
| `sets[].id` | Stable id. **Use the question bank's exam id** (e.g. `prep-math-04`) so imported questions attach to it. |
| `sets[].kind` | `chapter`, `pretest`, `mock` or `extra`. |
| `tasks[].type` | `practice` (problems in a range) · `timed` (range with a time limit) · `reviewWrong` (redo wrong answers; optional range for new problems) · `subjectReview` · `saturday` · `mock` (`mock`: round number) · `catchup` · `kickoff` · `exam`. |
| `from` / `to` | Problem range inside the set. Tasks with a range complete by themselves when every problem is answered; others have a "ทำเสร็จแล้ว" tick. |
| `minutes` | Optional time limit shown as a countdown. |
| `restWeekdays` | 0 = Sunday … 6 = Saturday. |

The validator lists every problem with its path (for example `tasks[12].set: ไม่พบชุด "x"`) before anything is changed.
Applying a plan replaces subjects, topics and practice history (the app offers a backup first); the question bank stays.
